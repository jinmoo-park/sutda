# Quick Task: Initial Chips Stepper UI

## Goal
방장 방 생성 화면과 초대받은 사람의 입장 화면에서 시작 칩 설정을 직접 숫자 입력이 아닌 만원 단위 증감 UI로 변경한다.

## Requirements
- 기본값은 100,000이어야 한다.
- 표시 값은 세 자리 쉼표를 포함해야 한다.
- 사용자가 직접 숫자를 타이핑하지 않고, 버튼으로 10,000 단위 증감해야 한다.
- 방 생성과 방 입장 플로우 모두 같은 동작을 사용해야 한다.
- 기존 socket payload의 `initialChips` 숫자 값은 유지해야 한다.

## Plan
1. 공통 `InitialChipsStepper` 컴포넌트를 추가한다.
2. `MainPage` 방 생성 폼의 number input을 stepper로 교체한다.
3. `RoomPage` 초대 링크 입장 폼의 number input을 stepper로 교체한다.
4. 엔트리 화면 CSS에 stepper 레이아웃과 버튼 스타일을 추가한다.
5. 클라이언트 빌드로 타입과 번들 오류를 확인한다.
