# Quick 260411-w10: 관전자 플레이어시트 누락 / 재경기 선 결정 / 자리비움 땡값 버그 3건 수정

## 한 줄 요약

관전자 입장 시 모든 플레이어 시트 표시, 동점 재경기에서 현재 선 유지 우선 규칙, 자리비움 플레이어 땡값 납부 제외 — 총 3건의 게임 정확성 버그 수정.

## 수정된 버그

### Bug 1: 관전자 플레이어시트 누락 (GameTable.tsx)

- **원인:** `me = players.find(p => p.id === myPlayerId)` 가 관전자에게 undefined 반환 → `mySeatIndex` 기본값 0 → 루프가 i=1부터 시작하여 seatIndex=0 플레이어 누락
- **수정:** `isObserver = !me` 분기 추가. 관전자 경로에서 모든 players를 seatIndex 오름차순으로 opponents 배열에 포함
- **파일:** `packages/client/src/components/layout/GameTable.tsx`
- **커밋:** `105ae6c`

### Bug 2: 동점 재경기 선 결정 규칙 미구현 (_startTieRematch)

- **원인:** dealer 탐색 루프가 `i=1`부터 시작 → 현재 dealer가 동점자여도 항상 건너뜀
- **수정:** `i=0`부터 시작하여 현재 dealer 자신이 tiedIds에 있으면 즉시 선으로 확정 (선 유지 규칙)
- **파일:** `packages/server/src/game-engine.ts`
- **커밋:** `503bded`

### Bug 3: 자리비움 플레이어 땡값 납부 포함 (_settleTtaengValue)

- **원인:** `diedPlayers = players.filter(p => !p.isAlive)` — isAbsent 플레이어도 isAlive=false이므로 납부 대상으로 오인
- **수정:** `filter(p => !p.isAlive && !p.isAbsent)` 로 자리비움 플레이어 명시적 제외
- **파일:** `packages/server/src/game-engine.ts`
- **커밋:** `503bded`
