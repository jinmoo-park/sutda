## 전체 기능 흐름

```
방장 AUTO 버튼 클릭
  → socket.emit('set-auto-shuffle', { roomId, enabled: true })
  → 서버: room.autoShuffle = true, io.to(roomId).emit('room-state', room)
  → 모든 클라이언트: roomState.autoShuffle = true 업데이트

게임 시작 → shuffling phase 진입
  → handleGameAction 처리 후 maybeAutoShuffle() 호출
  → engine.shuffle(dealer.id) 자동 실행
  → per-player game-state emit (cutting phase로 전환)
  → io.to(roomId).emit('auto-shuffle-trigger')
  → 모든 클라이언트: auto_shuffle SFX 재생 + autoMode ShuffleModal 표시
  → phase가 cutting으로 바뀌면 ShuffleModal 자동 닫힘
```
