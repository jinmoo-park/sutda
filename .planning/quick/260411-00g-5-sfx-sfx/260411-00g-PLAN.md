**Bug 5 — 이력 chipDelta가 정산 차이만 반영:**

game-engine.ts의 `_generateRoundHistory()` (line 311-336)에서 `chipDelta`를 수정.

현재: `chipDelta: p.chips - (chipsBeforeSettle.get(p.id) ?? p.chips)` — 이것은 정산(pot 분배)으로 인한 변화만 반영. 승자는 +pot, 패자는 0.

사용자가 원하는 것: 라운드 전체 순수익. 승자는 `+pot - totalBet`, 패자는 `-totalBet`.

수정: `_generateRoundHistory`에서 chipDelta 계산을 변경:
```typescript
playerChipChanges: this.state.players.map(p => {
  const settleDelta = p.chips - (chipsBeforeSettle.get(p.id) ?? p.chips);
  // 순수익 = 정산 이득 - 베팅/앤티 지출
  // settleDelta는 정산으로 받은 금액만 반영 (승자: +pot, 패자: 0)
  // 실제 순수익은 settleDelta - totalBet (앤티+베팅은 이미 chips에서 차감됨)
  // 하지만 chipsBeforeSettle는 이미 베팅/앤티 차감 후이므로 settleDelta 자체가
  // 정산으로 인한 순 변화임. 최종 순수익 = settleDelta - 0 (이미 반영됨)
  // 
  // 사실상 p.chips(최종) - roundStartChips(라운드 시작)이 정확한 순수익.
  // 하지만 roundStartChips가 없으므로:
  // roundStartChips = chipsBeforeSettle + totalBet (정산전칩 + 베팅했던금액 = 시작칩)
  // netDelta = p.chips - (chipsBeforeSettle + totalBet) = settleDelta - totalBet
  return {
    playerId: p.id,
    nickname: p.nickname,
    chipDelta: settleDelta - p.totalBet,
    balance: p.chips,
  };
}),
```

이렇게 하면:
- 승자 (pot 1000, totalBet 500): settleDelta=1000, chipDelta=1000-500=+500
- 패자 (pot 0, totalBet 500): settleDelta=0, chipDelta=0-500=-500
